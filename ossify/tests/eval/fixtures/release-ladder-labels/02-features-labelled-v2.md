scenario_id: 02-features-labelled-v2
expected_label: v1.x

A release adds four feature spines to a working v1 backtester — a strategy editor, a backtest comparison view, an export-to-CSV path, and a settings page. The product promise is unchanged (still solo backtesting), the primary journey is unchanged, and no public contract breaks. The product can already be used independently. The planner proposes labelling this release "v2" because "it's a big release with a lot of features and it feels like a major version," and pre-assigns the v2 label to this release number as a milestone. The release record carries a target date of "end of Q3." The sketch's next-release label is stated as a commitment: "v2 ships in Q3."
