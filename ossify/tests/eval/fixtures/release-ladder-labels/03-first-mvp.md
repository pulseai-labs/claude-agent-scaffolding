A release is the first at which the product can be used independently: a user can cold-start the system with no hand-holding, run a real data lifecycle end to end, and recover from a failure by a path appropriate to solo scale. Before this release the product was a skeleton the operator drove through guided flows; from this release it stands alone. The product promise is unchanged from the skeleton's, the primary journey is the skeleton's journey now fully real, and no public contract breaks. The release record carries no date. No label is pre-assigned; the label is confirmed at this release's planning from the evidence. The sketch's next-release label is a hypothesis: "next: v1.x as the first extensions land."
