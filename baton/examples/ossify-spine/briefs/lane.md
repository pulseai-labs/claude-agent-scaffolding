# Lane

1. Run `skill://run-spine` as `<spine> --external-executor --detach`. A halt row, a refusal, or a spine with more than one target_repo is a stop. Its caller-supplied procedure is this: for each request, write ossify's request record — its seven fields, unchanged, as one flat JSON object — plus `round` (1-based round number), `order` (1-based declared position) and `issued_at` (UTC ISO time), to the queue directory as `<work item>.json`: write a temp name without `.json` first, then `mv` it into place. Never execute, launch or wait for an item.
2. Write one done file, then end. If the read-out shows every round complete, write the rounds done file (`rounds.done`) instead of queueing, and do not run `/close`: `: > <Rounds done file from your message>`. Otherwise: `: > <Lane done file from your message>` (`lane.done`). This file is the stage's only success signal.
